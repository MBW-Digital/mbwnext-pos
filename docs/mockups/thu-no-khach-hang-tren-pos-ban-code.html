Còn mở

  • Thu bằng ví khi hình thức ví còn khai tài khoản 131 (cấu hình cũ trước PM-TASK-00106) đang báo lỗi. Chờ anh Quân chọn: chặn và báo đổi sang 6418, hoặc hỗ trợ cấu hình cũ.
  • Chưa thử QR SePay bằng tiền thật: chờ chốt tài khoản ngân hàng, mẫu mã thanh toán và API key webhook.
